# Maison Jiya Gestion Android 2.4

- remplace la page WebView « Page web non disponible » par un écran de reconnexion Maison Jiya ;
- réessaie automatiquement en cas de coupure réseau / erreur serveur ;
- permet une relance manuelle immédiate ;
- supprime le panneau flottant d’installation/notifications dans l’APK Android ;
- sur iPhone/PWA, le panneau est intégré au flux et disparaît après activation des notifications.
